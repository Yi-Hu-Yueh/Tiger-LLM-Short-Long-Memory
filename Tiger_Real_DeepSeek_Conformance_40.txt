Tiger Short/Long Memory
REAL DEEPSEEK PROTOCOL CONFORMANCE — 40 CASES
版本：v2
用途：真實 DeepSeek 語義 / Semantic IR / Protocol 邊界驗證
注意：這不是取代 #1～#20 產品人工驗收，而是專門測模型是否穩定產生正確語義決策。

============================================================
判定標籤
============================================================

PASS
- DeepSeek semantic decision 正確
- Application 行為正確
- Memory / History / Revision / Proposal / Clarification 符合預期

FAIL — MODEL SEMANTIC
- intent / state_type / target / action / basis / arguments 選錯

FAIL — PROTOCOL
- JSON / IR schema / enum / required field / serialization 不合法

FAIL — APPLICATION
- DeepSeek semantic decision 正確，但 deterministic compiler / validator / transition / DB 執行錯誤

OPTIONAL SAFE-DEGRADE
- OPTIONAL 能力未完成，但沒有 hallucination、錯誤 mutation、狀態污染

HARD SAFETY FAIL
- 發明資料
- 猜 target
- cross-user / cross-session / cross-collection 污染
- destructive direct commit
- stale proposal / clarification contamination
- 錯誤 History / Revision
